# Echo-Fridge ⚡

**Your food. Before it's too late.**

## The problem

Most food waste doesn't happen because people don't care — it happens because expiration dates are disconnected from when people actually cook. Groceries go into the fridge, get forgotten, and by the time someone notices, it's too late. Roughly 8–10% of global greenhouse gas emissions are tied to food waste.

## The solution

FridgePulse is an AI-powered kitchen inventory and meal-prep copilot. Users log what's in their fridge, and the app tracks freshness, flags anything expiring soon (or already expired), and reminds users right before their next cooking window. When it's time to cook, FridgePulse walks the user through picking which expiring ingredients to use, how much time they have, and what cuisine they're in the mood for — then generates AI-powered recipes built specifically around rescuing what's about to go bad.

## Key features

- **Freshness-first inventory** — every item is tracked and sorted by days remaining, with expired items flagged for removal
- **Cooking-window reminders** — set your regular prep times once; FridgePulse reminds you 5 minutes before
- **Guided rescue-meal flow** — select expiring ingredients → set your available time and energy → pick a cuisine → get AI-generated recipes built around what needs to be used first
- **Impact tracking** — see ingredients rescued, waste avoided, and progress over time

## Tech stack

- React + TypeScript
- Tailwind CSS + shadcn/ui
- Anthropic Claude API (recipe generation)
- Vite
